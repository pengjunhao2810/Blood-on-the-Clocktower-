## 三、关键历史缺陷与修复（回归记录）

1. 夜晚结束黑屏（Vue v-for+v-if 同元素运行时崩溃）→ template 包裹
2. 公聊输入框失效（canSpeakNow 未定义）→ 补充 computed
3. 挂起超时死锁 → 45 秒 AI 代选兜底
4. 提名阶段提前弹票数弹窗（ActiveVote 残留）→ StartGame 重置
5. 私聊消息重复（本地 push + 事件推送双写）→ 统一事件流
6. 提示卡片刷屏（多通道推送）→ 服务端 TipSent 幂等 + 前端 key 去重
7. 重启后房间堆积 → 空置 3 分钟自动复位 + 等待房间即销毁
8. 断线重连"连接未就绪" → send 等待连接窗口 + 重连恢复卡片
9. 提名死锁/重复执行 → 同时投票模型重构（可反复切换）
10. 多提名处决不比对票数 → 冷却到期统一汇总（唯一最高且过半）

## 四、性能与稳定性

- SQLite 连接池=1 + busy_timeout，无并发写锁死
- gin 日志落文件（后台启动不阻塞）
- 服务日志落 data/botc.log
- 每房间独立 goroutine Actor，房间互不阻塞
- AI 服务进程隔离，大模型不可用时模板降级
